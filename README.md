# AtendFácil — Atualizações

Este repositório contém **somente os pacotes de release** (artefatos) do AtendFácil para atualização das instalações on-premise.

- `atendfacil-<versão>.zip`: pacote da versão (servidor + painel).
- `checksums.txt`: sha256 dos pacotes — confira antes de instalar.

O código-fonte vive no repositório privado. Clientes: o app verifica e baixa daqui automaticamente; instalação manual em `docs/ATUALIZACOES.md` do pacote.
